the version change added no version-only staleness. All **159** task machine

## Limitations

The probes ran non-interactively; `-p` treats the folder as trusted, so the
interactive workspace-trust dialog, resume, compaction and subagent delivery were not
observed. Codex delivery in LEO and OR was not re-observed by this deployment; its
handlers were unchanged and statically current. These checks establish installation,
configuration and reminder delivery, not reduced goal drift.
