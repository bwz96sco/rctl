deployment the user asked whether hooks are still necessary; the analysis found that

offline wheel and runtime-constraint export, then


4.26.0. All **18 runtime files, 5 schema-directory files, 31 templates and 115 skill

## Limitations

The probe ran non-interactively; the interactive workspace-trust path and Codex
prompt delivery of the new layout were not observed. A governing question, Goal or
obligation whose first sentence exceeds 300 characters, or whose sentence break is
after an abbreviation such as "e.g.", still shows a marked partial line. The
project-only prompt reminder is unchanged and still truncates Current guidance.
Shorter reminders establish delivery format, not reduced goal drift.
