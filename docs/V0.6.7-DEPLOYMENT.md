# v0.6.7 deployment — 2026-10-14

**Deployed:** the global CLI is 0.6.7. Existing research projects were not accessed
or modified, as explicitly requested by the user.

`rctl init` now establishes one main repository containing research guidance,
task records, configuration and the optional vault. `code/` and `paper/` are
containers excluded from the main repository. Repeatable `--code-repo NAME` and
`--paper-repo NAME` options create independent repositories inside those containers.
Existing repositories, history, indexes and remotes are preserved. Already tracked
source paths and separately versioned vaults are flagged for explicit migration.

From that export, `uv build --offline --out-dir ../dist` built the deployment wheel,
and `uv export --locked --offline --no-dev --no-emit-project --no-hashes --format requirements-txt`
supplied `runtime-constraints.txt`. The clean-source wheel also passed the isolated
`scripts/smoke_package.py` check before installation. Installation used:

```sh

  --constraints /Users/zhangbowen/Projects/rctl/.work/release-0.6.7-20261014/runtime-constraints.txt \
  /Users/zhangbowen/Projects/rctl/.work/release-0.6.7-20261014/dist/rctl-0.6.7-py3-none-any.whl
```

The PATH entrypoint remains `/Users/zhangbowen/.local/bin/rctl`. `rctl --version`
reports `rctl 0.6.7`; `rctl init --help` exposes both named repository options.
