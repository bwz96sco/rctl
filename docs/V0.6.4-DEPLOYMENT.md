# v0.6.4 deployment — 2026-10-10

Released source: `4e6ede67edaf42ff90588ef2d5acdded072179c8`. After 0.6.3 the user objected to setting
`RCTL_TASK_PATH` at every host launch and then authorized releasing
[automatic reminder task selection](DEVELOPMENT.md#automatic-reminder-task-selection-10-october-2026):
without the variable, `context` and both host adapters use the project's only active
task and label it as selected automatically. Hook receipts record the selection
kind; the packaged research-task `SKILL.md` and `references/workspace.md` and the
generated host READMEs describe the rule. Schemas, controller and lifecycle commands
are unchanged, and commands that act on a task still require `TASK`.

## Limitations

The probe ran non-interactively; the interactive workspace-trust path and Codex
delivery of the automatic label were not observed. Automatic selection follows the
active phase only: a session working on a draft, or one of several active tasks,
still needs `rctl context TASK` or `RCTL_TASK_PATH`, and an active task left open
by another session is selected for every session in that project. Governing
questions whose first sentence exceeds 300 characters still show a marked partial
line.
