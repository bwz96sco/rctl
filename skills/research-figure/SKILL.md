# Research Figure

Own an individual display and its factual caption. Research-writing owns
paper-wide figure selection and argument placement; research-slides owns talk
planning. A standalone figure needs no separate manuscript plan.

## Starting contract

Establish the operation, reader question, source data/method, target surface,
dimensions and requested formats. Read the supplied brief, surrounding text and
caption when relevant. A diagram may explain structure without claiming a result.
An audit inspects the asset/provenance and returns findings; editing follows scope.

Choose panels, encoding, layout and production tools for that question. Use project
plotting/LaTeX sources where they own the asset. Plots/tables derive from actual
data and retain a reproducible generation route; diagrams retain editable source
or a structured specification. Preserve pairing IDs where relevant and identify
units, sample counts, metric definitions and uncertainty. Illustrative raster work
can use an available image-generation tool within the same evidence boundary.

## Completion and verification

Inspect the actual render at target scale for readability, clipping, labels and
fidelity to source values/topology. Script or format success alone establishes no
visual correctness. Check the caption against the display and sources: panel
labels, encodings, units, sample counts, uncertainty, takeaway and scope as applicable.

Creation/revision delivers the requested asset, source/generation route and
inspected figure/caption. An audit delivers anchored findings and uncheckable
properties; missing source limits reproducibility judgment. Caption-only and
integration work check the affected surface without rebuilding an unchanged asset.

Keep the canonical caption in manuscript source when integrating; preserve the
existing figure label and requested slot. Report mismatches between the intended
takeaway and actual evidence, including neutral or unfavorable findings. Broader
argument changes follow the writing/talk request.

Reuse project notes or the bound vault's `figures/<slug>/`, otherwise
`artifacts/research-figure/<slug>/`. Final assets live in the paper/talk repository.
Prefer vectors for exact plots/diagrams; choose raster for photos or imagery.
Managed lifecycle and acceptance stay with research-task.
